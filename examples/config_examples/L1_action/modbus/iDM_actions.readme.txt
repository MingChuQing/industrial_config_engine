#   iDM 系列步进电机 - L1 原子操作手册

## 一、概述

### 1.1 适用范围

本手册适用于  iDM-RS(V2.0) 系列智能驱控一体式步进电机，基于 Modbus RTU 协议通信，包含以下型号：

| 型号 | 机座 | 保持扭矩 | 峰值电流 |
|------|------|---------|----------|
| iDM42-RS06(V2.0) | 42 | 0.6 N·m | 2.2A |
| iDM42-RS08(V2.0) | 42 | 0.8 N·m | 2.2A |
| iDM57-RS13(V2.0) | 57 | 1.3 N·m | 4.5A |
| iDM57-RS23(V2.0) | 57 | 2.3 N·m | 7.0A |

### 1.2 文档结构

每个原子操作包含：
- **文件名**：文件命名规范
- **功能描述**：操作的作用
- **参数列表**：输入参数说明
- **JSON 模板**：完整的配置示例
- **Modbus 报文示例**：对应的十六进制报文

### 1.3 目录结构


## 三、各原子操作详解

### 3.1 write_register.u16_u16

**功能**：写入单个 16 位 Modbus 寄存器

**参数**：

| 参数 | 类型 | 范围 | 说明 |
|------|------|------|------|
| register | u16 | 0~65535 | 寄存器地址 |
| value | u16 | 0~65535 | 写入值 |

**示例**：写入控制字使能 (0x1801 = 0x0001)

```json
{
    "type": "modbus_write_verify",
    "protocol": "modbus",
    "request": "06 18 01 00 01",
    "response": "06 18 01 00 01",
    "timeout_ms": 3000
}
```

### 3.2 read_register.u8_u16_u16

**功能**：读取单个 16 位寄存器

**参数**：

| 参数 | 类型 | 范围 | 说明 |
|------|------|------|------|
| register | u8 | 0~255 | 寄存器地址 |
| timeout | u16 | 500~10000 | 超时(ms)，默认2000 |

**示例**：读取运行状态 (0x1003)

```json
{
    "type": "modbus_read_cache",
    "protocol": "modbus",
    "request": "03 10 03 00 01",
    "parse": { "start_byte": 2, "length": 2, "endian": "big", "type": "uint16" },
    "timeout_ms": 2000
}
```

**返回状态位说明**：

| Bit | 含义 |
|-----|------|
| Bit0 | 故障 |
| Bit1 | 使能 |
| Bit2 | 运行 |
| Bit4 | 指令完成 |
| Bit5 | 路径完成 |
| Bit6 | 回零完成 |

### 3.3 read_register_32.u8_u16_u16

**功能**：读取 32 位值（两个连续寄存器）

**参数**：

| 参数 | 类型 | 范围 | 说明 |
|------|------|------|------|
| register | u8 | 0~255 | 寄存器起始地址 |
| timeout | u16 | 500~10000 | 超时(ms)，默认2000 |

**示例**：读取电机位置 (0x602C, 0x602D)

```json
{
    "type": "modbus_read_cache",
    "protocol": "modbus",
    "request": "03 60 2C 00 02",
    "parse": { "start_byte": 2, "length": 4, "endian": "big", "type": "int32" },
    "timeout_ms": 2000
}
```

### 3.4 check_register.u8_s_u16_u16

**功能**：读取寄存器并检查条件

**参数**：

| 参数 | 类型 | 范围 | 说明 |
|------|------|------|------|
| register | u8 | 0~255 | 寄存器地址 |
| condition | s | eq/ne/lt/le/gt/ge | 比较条件 |
| compare_value | u16 | 0~65535 | 比较值 |
| timeout | u16 | 500~10000 | 超时(ms)，默认2000 |

**示例**：检查回零是否完成 (0x1003 & 0x40)

```json
{
    "type": "modbus_read_check",
    "protocol": "modbus",
    "request": "03 10 03 00 01",
    "parse": { "start_byte": 2, "length": 2, "endian": "big", "type": "uint16" },
    "check": { "condition": "eq", "value": 64 },
    "timeout_ms": 2000
}
```

### 3.5 write_control_word.u16

**功能**：写入控制字 (0x1801)

**控制字值说明**：

| 值 | 功能 |
|----|------|
| 0x0001 | 使能 |
| 0x1111 | 复位当前报警 |
| 0x2211 | 保存参数到 EEPROM |
| 0x2233 | 恢复出厂设置 |
| 0x4001 | JOG 正转 |
| 0x4002 | JOG 反转 |

**示例**：使能电机

```json
{
    "type": "modbus_write_verify",
    "protocol": "modbus",
    "request": "06 18 01 00 01",
    "response": "06 18 01 00 01",
    "timeout_ms": 3000
}
```

### 3.6 trigger_pr.u16

**功能**：触发 PR 路径 (0x6002)

**触发值说明**：

| 值 | 功能 |
|----|------|
| 0x001P (P=0~F) | 触发路径 P |
| 0x0020 | 触发回零 |
| 0x0040 | 急停 |

**示例**：触发路径 0

```json
{
    "type": "modbus_write_verify",
    "protocol": "modbus",
    "request": "06 60 02 00 01",
    "response": "06 60 02 00 01",
    "timeout_ms": 3000
}
```

### 3.7 set_pr_mode.u16

**功能**：设置 PR 路径模式 (0x6200)

**模式值说明**：

| 值 | 模式 |
|----|------|
| 0x0001 | 绝对位置 |
| 0x0002 | 速度模式 |
| 0x0003 | 回零 |

### 3.8 read_status

**功能**：读取运行状态 (0x1003)

**状态值说明**：同 3.2 节

### 3.9 read_alarm

**功能**：读取当前报警 (0x2203)

**报警码说明**：

| 值 | 含义 |
|----|------|
| 0x00E0 | 过流 |
| 0x00C0 | 过压 |
| 0x0152 | 锁轴故障 |
| 0x0240 | EEPROM 故障 |
| 0x00F0 | 过温 |
| 0x0210 | IO 配置重复 |

### 3.10 set_position_32.u32

**功能**：设置 32 位位置值

**参数**：

| 参数 | 类型 | 范围 | 说明 |
|------|------|------|------|
| position | u32 | 0~4294967295 | 位置值(脉冲数) |

**示例**：设置位置 200000 (0x00030D40)

```json
{
    "type": "modbus_write_verify",
    "protocol": "modbus",
    "request": "06 62 01 00 03",
    "response": "06 62 01 00 03",
    "timeout_ms": 3000
}
```
（注：需要分别写入高位 0x6201 和低位 0x6202）

bool Engine::loadActionBundle(const std::string& bundle_path) {
    std::vector<Action> actions;
    std::string error;
    if (action_loader_->loadActionBundle(bundle_path, actions, error)) {
        for (const auto& action : actions) {
            // 缓存或注册 action
            std::cout << "[ACTION] Loaded: " << action.description << std::endl;
        }
        logDebug("Loaded action bundle: " + bundle_path);
        return true;
    }
    logError("Failed to load action bundle: " + error);
    return false;
}
