# 气密性检测系统 - 完整逻辑描述

## 一、系统概述

气密性检测是工业自动化中常见的工艺环节，用于验证产品（如电池包、管道、密封件等）的密封性能是否达标。

---

## 二、核心工艺逻辑

### 2.1 总体流程

```
开始
  ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段1：准备阶段                                             │
│  ├── 检查设备状态（气源压力、夹具位置、密封圈完好）        │
│  ├── 启动真空泵/气泵（建立气源）                           │
│  └── 夹具闭合（密封产品）                                  │
└─────────────────────────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段2：充气阶段（Pressure Build）                          │
│  ├── 打开充气阀，向产品腔体充气                            │
│  ├── 监测压力上升曲线                                      │
│  └── 达到设定压力后关闭充气阀                              │
└─────────────────────────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段3：保压阶段（Dwell / Stabilization）                   │
│  ├── 等待压力稳定（压力波动＜阈值）                        │
│  ├── 记录稳定压力值 P_start                                │
│  └── 开始计时（保压时间，如30秒）                          │
└─────────────────────────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段4：检测阶段（Test / Measurement）                      │
│  ├── 持续监测压力变化                                      │
│  ├── 计算压降值 ΔP = P_start - P_end                      │
│  └── 计算泄漏率 LeakRate = ΔP / Δt                        │
└─────────────────────────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段5：判断阶段（Pass/Fail Judgment）                      │
│  ├── 泄漏率 ≤ 标准值 → 合格（PASS）                       │
│  ├── 泄漏率 > 标准值 → 不合格（FAIL）                     │
│  └── 记录测试数据                                          │
└─────────────────────────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段6：结束阶段                                             │
│  ├── 打开排气阀，释放压力                                  │
│  ├── 夹具打开                                              │
│  ├── 停止真空泵/气泵（可选）                               │
│  ├── 标记结果（合格/不合格）                               │
│  └── 准备下一个产品                                        │
└─────────────────────────────────────────────────────────────┘
```

## 三、详细逻辑拆解

### 3.1 准备阶段

| 步骤 | 逻辑描述 |
|------|----------|
| S1.1 | 检查外部气源压力是否在正常范围（0.4~0.6MPa） |
| S1.2 | 检查夹具是否在打开状态 |
| S1.3 | 检查密封圈是否在位（通过传感器检测） |
| S1.4 | 启动真空泵或气泵，等待压力建立 |
| S1.5 | 闭合夹具，密封产品腔体 |
| S1.6 | 检查密封是否到位（密封圈压缩量检测） |
| S1.7 | 打开先导阀，接通测试气路 |

### 3.2 充气阶段

| 步骤 | 逻辑描述 |
|------|----------|
| S2.1 | 打开充气电磁阀 |
| S2.2 | 开始监测压力传感器读数 |
| S2.3 | 压力上升速率计算（dP/dt），判断是否有大漏 |
| S2.4 | 若压力上升速率异常低 → 判断为"大漏"（大漏缺陷） |
| S2.5 | 当压力达到目标值（如100kPa）→ 关闭充气阀 |
| S2.6 | 记录充气时间 T_fill |

### 3.3 保压阶段

| 步骤 | 逻辑描述 |
|------|----------|
| S3.1 | 开始保压计时（通常3~10秒） |
| S3.2 | 监测压力波动幅度 |
| S3.3 | 若压力波动 ≤ 阈值（如0.1kPa/s）→ 压力稳定 |
| S3.4 | 记录稳定后的压力值 P_initial |
| S3.5 | 若压力在保压期间快速下降 → 判断为"大漏" |

### 3.4 检测阶段

| 步骤 | 逻辑描述 |
|------|----------|
| S4.1 | 开始正式检测计时（通常10~60秒） |
| S4.2 | 以固定采样频率（如100Hz）采集压力数据 |
| S4.3 | 实时计算压力变化趋势 |
| S4.4 | 检测结束时记录最终压力 P_final |
| S4.5 | 计算压降 ΔP = P_initial - P_final |
| S4.6 | 计算泄漏率 LeakRate = ΔP / 检测时间 |

### 3.5 判断阶段

| 步骤 | 逻辑描述 |
|------|----------|
| S5.1 | 判断泄漏率是否 ≤ 规格标准（如0.5kPa/min） |
| S5.2 | 若合格 → 产品标记为PASS |
| S5.3 | 若不合格 → 产品标记为FAIL |
| S5.4 | 记录所有测试数据（压力曲线、泄漏率、判定结果） |
| S5.5 | 显示结果并通过指示灯/蜂鸣器提示 |

### 3.6 结束阶段

| 步骤 | 逻辑描述 |
|------|----------|
| S6.1 | 打开排气阀，释放腔体内压力 |
| S6.2 | 等待压力归零（压力 ≤ 阈值） |
| S6.3 | 打开夹具 |
| S6.4 | 根据结果分拣产品（合格/不合格） |
| S6.5 | 打印/保存测试报告 |
| S6.6 | 复位系统，等待下一个产品 |

## 四、关键参数

### 4.1 工艺参数

| 参数名 | 典型值 | 说明 |
|--------|--------|------|
| 测试压力 | 50~200 kPa | 根据产品要求设定 |
| 充气时间 | 3~10秒 | 达到目标压力所需时间 |
| 保压时间 | 3~10秒 | 压力稳定等待时间 |
| 检测时间 | 10~60秒 | 泄漏检测持续时间 |
| 排气时间 | 2~5秒 | 释放压力时间 |
| 泄漏率标准 | ≤0.5 kPa/min | 合格判定阈值 |
| 大漏阈值 | ≥5 kPa/s | 充气阶段检测大漏 |

### 4.2 传感器采集

| 传感器 | 用途 | 采样频率 |
|--------|------|----------|
| 压力传感器 | 实时监测腔体压力 | 100~1000 Hz |
| 温度传感器 | 温度补偿计算 | 1~10 Hz |
| 流量传感器 | 测量泄漏流量（可选） | 10~100 Hz |

## 五、异常处理逻辑

### 5.1 异常类型与处理

| 异常类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| **气源异常** | 外部气压低于0.3MPa | 停止测试，报警提示 |
| **大漏** | 充气阶段压力上升速率过慢 | 直接判定FAIL，立即排气 |
| **压力超限** | 压力超过安全阈值（如200kPa） | 紧急排气，终止测试 |
| **传感器故障** | 传感器读数异常或无信号 | 停止测试，报警 |
| **密封圈失效** | 密封圈在位传感器异常 | 停止测试，报警 |
| **夹具故障** | 夹具未闭合到位 | 停止测试，报警 |
| **测试超时** | 总测试时间超过设定值 | 停止测试，记录为超时 |

### 5.2 紧急停止逻辑

```
紧急停止触发
  ↓
立即关闭所有气阀（充气阀、排气阀）
  ↓
打开排气阀快速泄压
  ↓
停止所有泵和电机
  ↓
记录当前状态和测试数据
  ↓
报警提示操作员
  ↓
等待人工复位
```

## 六、与上料系统的协同

### 6.1 完整工艺流程（含上料）

```
上料系统（ 电机）
  ├── 产品从料盘取出
  ├── 搬运到测试工位
  └── 放置到夹具中
        ↓
气密性检测系统
  ├── 夹具闭合
  ├── 执行检测流程
  └── 输出结果（PASS/FAIL）
        ↓
下料系统
  ├── 夹具打开
  ├── PASS → 放入合格品区
  ├── FAIL → 放入不合格品区
  └── 搬运到下一工位（PASS产品）
```

### 6.2 协同逻辑

| 协同点 | 上料系统动作 | 气密性检测动作 |
|--------|-------------|---------------|
| 上料到位 | 运动到放料位，放置产品 | 等待产品就位 |
| 检测开始 | 离开检测位，等待 | 执行检测流程 |
| 检测完成 | 等待结果 | 输出PASS/FAIL |
| 下料取料 | 根据结果分拣取料 | 夹具打开，释放产品 |

## 七、特殊场景处理

### 7.1 温度补偿

由于温度变化会影响压力读数，需要进行温度补偿：

```
补偿公式：
  P_corrected = P_measured × (T_reference / T_actual)
  
  其中：
  P_corrected = 补偿后的压力
  P_measured = 实测压力
  T_reference = 参考温度（如20℃）
  T_actual = 实际环境温度
```

### 7.2 多通道并行检测

对于多工位并行检测：

```
主控流程
  ├── 工位1：执行独立的检测循环
  ├── 工位2：执行独立的检测循环
  ├── 工位3：执行独立的检测循环
  └── 工位4：执行独立的检测循环

每个工位独立运行，互不影响
主控负责调度和汇总结果
```

### 7.3 数据记录要求

| 数据项 | 用途 |
|--------|------|
| 时间戳 | 追溯检测时间 |
| 产品ID/条码 | 追溯产品信息 |
| 压力曲线（采样点） | 质量分析和趋势监控 |
| P_initial、P_final | 计算压降 |
| 泄漏率 | 判定依据 |
| 温度数据 | 补偿计算 |
| 测试结果（PASS/FAIL） | 产品分拣 |
| 操作员信息 | 责任追溯 |

## 八、总结

### 8.1 核心逻辑要点

| 要点 | 说明 |
|------|------|
| **状态机设计** | 每个阶段是一个状态（空闲→准备→充气→保压→检测→判断→结束） |
| **时序控制** | 严格按照时间序列执行，每个阶段有明确的进入/退出条件 |
| **异常处理** | 任何阶段都可能出现异常，需设计完善的异常处理机制 |
| **数据驱动** | 所有判断基于传感器数据，需保证数据准确性和实时性 |
| **可追溯性** | 所有测试数据需完整记录，便于质量追溯 |

### 8.2 与您现有系统结合

基于您已有的 电机上料系统，气密性检测可以作为**L3 Group**中的独立模块：

```
L3 Group: 完整生产流程
  ├── L3 Group: 上料系统（已有）
  │   ├── PR1精确定位（取料）
  │   └── PR2精确定位（放料）
  ├── L3 Group: 气密性检测
  │   ├── 准备阶段
  │   ├── 充气阶段
  │   ├── 保压阶段
  │   ├── 检测阶段
  │   └── 判断阶段
  └── L3 Group: 下料分拣
      ├── PASS → 合格品区
      └── FAIL → 不合格品区
```
