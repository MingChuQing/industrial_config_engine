#  电机上料系统（修正版，符合Node规范）

## 一、修正原则

| 原则 | 说明 |
|------|------|
| **Node只能包含一个action** | Node内部不能嵌套Node |
| **Node的on_success/on_failure只能放L1** | 不能放Node或Group |
| **循环/顺序逻辑放到Group层** | Group负责编排多个Node |
| **Node负责单一状态判断** | 一个Node = 一个动作 + 一个判断 |

### 4.1 运行PR并等待完成Group

**文件：`L3_group/leadshine/run_pr_with_wait.group`**

```json
{
    "type": "group",
    "name": "运行PR并等待完成",
    "description": "启动PR运行，然后循环检测直到运动完成",
    "params": [
        { "index": 0, "name": "pr_number", "type": "u8", "desc": "PR点位号" },
        { "index": 1, "name": "timeout", "type": "u16", "default": 30000, "desc": "超时(毫秒)" }
    ],
    "steps": [
        {
            "type": "node",
            "name": "启动PR${pr_number}",
            "path": "L2_node/leadshine/start_pr_run.u8.r_b_start_result",
            "params": ["${pr_number}"]
        },
        {
            "type": "while",
            "name": "等待运动完成",
            "condition": {
                "type": "expression",
                "expression": "${loop_count} * 100 < ${timeout}"
            },
            "max_iterations": 300,
            "steps": [
                {
                    "type": "node",
                    "name": "检查运动状态",
                    "path": "L2_node/leadshine/check_motion_done.r_b_motion_done",
                    "params": []
                },
                {
                    "type": "break_if",
                    "condition": {
                        "type": "expression",
                        "expression": "${motion_done} == true"
                    }
                },
                {
                    "type": "node",
                    "name": "等待100ms",
                    "path": "L2_node/wait/wait_ms.u16.r_b_wait_done",
                    "params": [100]
                }
            ]
        }
    ],
    "on_success": [
        {
            "type": "log",
            "message": "PR${pr_number}运行完成"
        }
    ],
    "on_failure": [
        {
            "type": "log",
            "message": "PR${pr_number}运行超时"
        },
        {
            "type": "popup",
            "message": "PR${pr_number}运行超时，请检查电机",
            "level": "error"
        }
    ]
}
```
