# 气密性检测系统 - 配置文件设计

## 一、L1 Action 文件列表（共19个）

### 1.1 数字量输入/输出控制

| 文件名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `digital_read.u8.r_b_digital_state` | `register`: u8 | `digital_state`: b | 读取数字量输入状态 |
| `digital_write.u8_b.r_b_write_result` | `register`: u8, `value`: b | `write_result`: b | 写入数字量输出 |
| `digital_write_on.u8.r_b_write_result` | `register`: u8 | `write_result`: b | 数字量输出置ON |
| `digital_write_off.u8.r_b_write_result` | `register`: u8 | `write_result`: b | 数字量输出置OFF |

| 文件名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `read_analog.u8.r_f_analog_value` | `channel`: u8 | `analog_value`: f | 读取模拟量通道值(0-10V/4-20mA) |
| `read_pressure.u8.r_f_pressure` | `channel`: u8 | `pressure`: f | 读取压力传感器值(kPa) |
| `read_temperature.u8.r_f_temperature` | `channel`: u8 | `temperature`: f | 读取温度传感器值(℃) |

### 1.3 Modbus通信

| 文件名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `read_modbus_register.u8_u16.r_u16_register_value` | `addr`: u8, `reg`: u16 | `register_value`: u16 | 读取Modbus寄存器 |
| `write_modbus_register.u8_u16_u16.r_b_write_result` | `addr`: u8, `reg`: u16, `val`: u16 | `write_result`: b | 写入Modbus寄存器 |

### 1.4 气阀控制

| 文件名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `open_fill_valve.r_b_valve_result` | 无 | `valve_result`: b | 打开充气阀 |
| `close_fill_valve.r_b_valve_result` | 无 | `valve_result`: b | 关闭充气阀 |

| 文件名 | 参数 | 返回值 | 说明 |

### 1.6 数据计算与存储

| 文件名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
