文件：L3_group/pump_down.group.json
json
{
  "type":"group",
  "name":"抽真空",
  "mode":"sequence",
  "body":[
    {"type":"node","template":"open_valve","params":[0x01]},
    {"type":"node","template":"close_valve","params":[0x02]},
    {"type":"node","template":"start_pump"},
    {
      "type":"group",
      "mode":"loop",
      "loop":{"type":"do_while","condition":"${pressure} > 5","timeout_ms":300000,"interval_ms":500},
      "body":[{"type":"node","template":"read_pressure","result_key":"pressure"}],
      "on_success":[
        {"type":"node","$ref":"stop_pump"},
        {"type":"log","message":"抽真空完成"}
      ],
      "on_timeout":[
        {"type":"node","$ref":"stop_pump"},
        {"type":"popup","message":"抽真空超时，已停止","level":"error"}
      ]
    }
  ]
}

执行流程
text
打开阀门1
    ↓
关闭阀门2
    ↓
启动真空泵
    ↓
┌─ do-while 循环（最长5分钟）──┐
│  读取压力 → 存入 pressure      │
│  若 pressure ≤ 5 → 退出（成功）│
│  等待 500ms                    │
└────────────────────────────────┘
    ↓
停止真空泵
    ├── 成功 → 记录日志
    └── 超时 → 弹框提示
